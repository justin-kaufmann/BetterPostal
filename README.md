# BetterPostal
DE: Postfach-Upgrade für WoW Retail: Du bestimmst, welche Briefe geöffnet und welche Gegenstände eingesammelt werden. Dazu Filter, Seitensprünge, automatische Fortsetzung beim erneuten Öffnen und optionales Löschen. EN: Smarter mail: choose what to open/loot, filter mail/items, jump pages, auto-resume and optionally delete collected mail.
